# E11 — 更强的非线性读出会不会翻盘

生成：2026-10-29　·　协议：`results/E11_readout/E11_PREREG.md`

数据：`E11_cells.json`；判定：`E11_verdict.json`；V-JEPA 的多划分补充：`E11_vjepa_probe_seeds.json`。

---

## 1. 结论先行

**不会翻盘。四格全部 `robust_to_readout`。**

| 格 | 线性（基准）| Nyström（最强合格非线性）| Δ | 判定 |
|---|---|---|---|---|
| Wan2.1-1.3B @ LikePhys | 32.90% | **25.28%** | −7.62 pp | robust |
| HunyuanVideo @ LikePhys | 27.01% | **35.11%** | +8.10 pp | robust |
| V-JEPA 2 @ LikePhys | 49.36% | **45.16%** | −4.20 pp | robust |
| Wan2.1-1.3B @ IntPhys 2 | 91.21% | **85.87%** | −5.34 pp | robust |

**每一格的最强合格读出都和线性档落在 50% 的同一侧。** D1 的 pass/fail 判定不依赖读出复杂度。

**线性档逐位复现了 E8 的交付值**（32.90 / 27.01 / 91.21，与 32.9 / 27.0 / 91.2 一致），
这是本轮的自检门槛：**做不到这一步，三档之间就没法比。**

---

## 2. 为什么这次和旧 §5.3.2 不一样

旧版的问题是它自己的 MLP **比线性 probe 差**（`EXPERIMENTS.md` §5.3.2 的 0.8776 vs 0.9686），
所以「非线性没缩小差距」这句话测的是**读到的东西更少**，不是**容量不够**。

**一处必须说准的措辞**：E11 里 MLP 的 `unconverged_folds = 0`（四格全部收敛，
`max_iter` 5000 且 early stopping 正常触发），所以**不能**写成"优化没收敛"。
正确的描述是 **在 n≈750 上泛化失败/过拟合**：它拟合训练折很好，测试折反而比线性档差。
这是**估计问题**而不是**优化问题**，两者的补救手段完全不同。

E11 加了一道**前置门槛（Q2）**：任何读出只要比线性档低超过 0.01 AUC，就**不许参与判定**。

结果这道门槛**把 MLP 全部拒收了**：

| 格 | MLP 的 AUC 比线性档低 |
|---|---|
| Wan2.1-1.3B @ LikePhys | −0.0324 |
| HunyuanVideo @ LikePhys | −0.0318 |
| V-JEPA 2 @ LikePhys | −0.0358 |
| Wan2.1-1.3B @ IntPhys 2 | **−0.1271** |

**而 MLP 的 D1 看起来非常"戏剧"**：77.0% / 86.7% / 78.3% / 88.7%，全部远高于线性档。
如果只看这几个数，会得出"更强的非线性把训练贡献推到 87%"的结论 —— **但那完全是假的**：

| 格 | MLP real / random | 线性 real / random |
|---|---|---|
| Wan2.1-1.3B @ LikePhys | 0.9065 / **0.5937** | 0.9389 / 0.7945 |
| HunyuanVideo @ LikePhys | 0.9107 / **0.5547** | 0.9425 / 0.8230 |
| V-JEPA 2 @ LikePhys | 0.9411 / **0.5959** | 0.9769 / 0.7332 |
| Wan2.1-1.3B @ IntPhys 2 | 0.5230 / **0.5026** | 0.6502 / 0.5132 |

**看第二列**：MLP 把 `random` 臂砸到 0.50–0.60，`real` 臂只掉 0.03 ——
两者相减后**分母（real − 0.5）塌得比分子快**，D1 就被机械地推高。
最后一格最极端：MLP 的 `random` 是 0.5026，**几乎等于抛硬币**，
于是 D1 的分母只剩 0.023，任何微小的分子都会被放大成"训练贡献"。

**这是本轮最重要的方法学产出**：`random` 臂的塌陷会把 D1 推高，而 D1 的公式对此**毫无防御**。
旧 §5.3.2 差点掉进同一个坑（它的 MLP 也把 D1 从 28.5% 推到了 43.9%），只是没跨过阈值所以没被发现。

## 3. Nyström 为什么是合格的"更强读出"

设计动机（预注册 §2）：**它在 x 上非线性，但在读出权重上仍是凸的**，只有一个凸的优化问题，
所以不会像 256 隐层 MLP 那样在 n≈750 上过拟合。

实测证实了这一点：四格里 Nyström 的 AUC **都不低于**线性档（Δ +0.0017 到 +0.0111）。

但它**也没有系统性地把 D1 推高**：两格降（−7.62、−5.34）、一格升（+8.10）、一格小降（−4.20）。
方向不一致 → 这些变化是**读出选择的噪声**，不是容量效应。

### 3.1 一个必须说的细节：Δ 超过 2.51 pp 的噪声线

`hunyuan` 的 +8.10 pp 与 `wan21_1b3@likephys` 的 −7.62 pp 都**超过** E16 测得的
probe 划分噪声（2.51 pp）。所以不能说"变化在噪声内"。

**但方向相反**：同一批方法，一处把 D1 推高 8 个点、另一处压低 7.6 个点。
若这是"容量效应"，两处的符号应该一致。**符号不一致本身就说明它不是容量效应。**

→ 正确的表述：**读出复杂度能在 ±8 个百分点内移动 D1，但移动方向随机，因此不能用来预测
  "训练贡献是否超过 50%"。** 而四格里离阈值最近的（V-JEPA 49.36%）在更强读出下是**往下**走的
  （45.16%），所以**离翻盘更远，不是更近**。

## 4. 判定细节：V-JEPA 那一格特殊处理

V-JEPA 在 LikePhys 上的 D1 **不是单点数**（E15 已证明它在 43.8–54.0% 之间随 probe 划分摆动）。
所以它的这一格**不用 seed 1000 的单点**，而用**六个划分的均值**：

| 读出 | 6 划分均值 | sd | 低于 50% 的划分 |
|---|---|---|---|
| 线性 | **49.36%** | 2.25 | 5/6 |
| Nyström | **45.16%** | 3.70 | 5/6 |

若不这样处理，线性档会是 51.11%（seed 1000），**连 E8 交付的 49.4% 都复现不了**，
三档比较就失去意义。数据见 `E11_vjepa_probe_seeds.json`。

## 5. 对结论的影响

**E11 排除了一条重要的退路。** 之前能写的是：

> 「在我们能负担的读出设定下，非线性没有缩小 trained 与 random 的相对差距；
> 但不能排除更强的读出会改变结论。」（`EXPERIMENTS.md` §5.3.2 原话）

**现在可以写**：

> 在一个**不弱于线性基准**的非线性读数下（Nyström 核映射，AUC ≥ 线性基准），
> 四格的 D1 判定**全部不变**。更弱的非线性读出（MLP）会被前置门槛拒收，
> 因为它把 `random` 臂打到 0.50–0.60，**机械地把 D1 推高到 77–87%**，
> 那是 `random` 臂塌陷造成的分母效应，不是容量效应。

→ **仍需保留的限定**：只测了 Nyström 一种非线性，且只有 4 个格。
  真正的最强读出（temporal attention probe，Punzo 那类）**未测**，
  这条退路没有被彻底封死。
