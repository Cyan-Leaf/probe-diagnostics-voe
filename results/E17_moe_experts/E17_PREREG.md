# E17 预注册：MoE 双专家（Wan2.2-T2V-A14B）作为结构对照

**写于任何 A14B 提取之前：2026-10-29**
上游协议：`PREREG.md` D1 / D2 + `E8_PREREG.md`，参考格 `layer 16 / t=600`

---

## 1. 这个模型为什么值得加（一条独有的对照轴）

到此为止覆盖了 6 个模型族，但它们都是**单一去噪网络**。Wan2.2-T2V-A14B 是唯一一个
**同一份权重包里装了两个独立的专家网络**：

| | `transformer` | `transformer_2` |
|---|---|---|
| 层数 | 40 | 40 |
| 角色 | **高噪声专家**（boundary 之前）| **低噪声专家**（boundary 之后）|
| 参数量 | 14B | 14B |

两者**各自从不同的噪声区间训练**，在推理时按 timestep 切换。这给了本项目一个
**任何其他模型都无法提供的对照**：

> **同样的输入、同样的架构、同样的数据、同样的训练流程，
> 只是训练时看到的噪声区间不同 —— D1/D2 会不会变？**

如果两个专家给出同样的判定 → D1/D2 与"训练时聚焦哪个噪声区间"无关，这比再加一个
不同家族的模型**证据更强**，因为它把家族、架构、数据、规模全部固定住了。

## 2. 三个格，问三个不同的问题

### 格 A（主格，与 E8 可比）：跑到 boundary 之上，用低噪声专家

- 用 `transformer_2`（低噪声专家），t=600
- 这是 Wan2.2 的正常推理路径（t=600 在 boundary 之后）
- **与 E8 全部 backbone 同口径**，可直接进 §14 的表

### 格 B（主格，与 E8 可比）：高噪声专家

- 用 `transformer`（高噪声专家），t=600
- **这不是它的正常推理区间**（它在 t > boundary 时才启用），
  但它仍然是一个训练过的 14B 去噪网络，问题"它读不读得出物理"仍然成立
- **必须声明这是一次 out-of-range 使用**，见 §4.1

### 格 C（本次独有）：同 t、两专家之差

- `Δ = D1(low-noise expert) − D1(high-noise expert)`
- **这是唯一能回答"噪声区间专精是否影响可读性"的量**
- 因为两个专家共享**完全相同的**架构、数据、训练超参，任何差异只能来自噪声区间

## 3. 判据（写死）

### Q1：两个专家的 D1 是否都 ≥ 50%？（与 E8 在 IntPhys 2 上的方向一致）

- 两个格都 ≥ 50% → **与 E8 的 6/7 pass 一致**，结论扩展到 7 个族
- 一个 pass 一个 fail → **本身是结论**：D1 的判定对"噪声专精"敏感
- 两个都 < 50% → **与 E8 矛盾**，必须优先复核提取管线（因为 E8 在 IntPhys 2 上一向 pass）

### Q2：两专家之差 Δ 是否超过 probe 噪声？

E16 实测 probe 划分的 sd：**IntPhys 2 上 1.98–3.41（中位 2.51）**。

- `|Δ| < 2.51` → 判 **`within_noise`**：不能用这个模型声称"噪声区间影响 D1"
- `|Δ| ≥ 2.51` → 判 **`exceeds_noise`**，并报告 Δ 的方向

**为什么用 2.51（IntPhys 2 的中位 sd）而不是 0：** 因为 E16 已经证明同一批特征、
同一个 probe、只换划分就能让 D1 动 2–3 个百分点。用一个更小的阈值等于把噪声当信号。

### Q3：D2 是否重现？

与 E8 同判据：`AUC(外观) ≥ AUC(物理)` → fail。**两个专家分别报，不合并。**

## 4. 必须先声明的偏离

### 4.1 格 B 是 out-of-range 使用

高噪声专家在正常推理中只处理 t > boundary（Wan2.2 的默认 boundary 约在 σ=0.875 附近）。
在 t=600（σ=0.600）上用它，**它没有在这个噪声水平上被训练过**。

→ 后果：格 B 的 AUC 数值**不能**读成"这个专家在该噪声下的真实能力"。
→ 但它仍然有意义：它回答的是"一个在别的噪声区间训练的 14B 去噪网络，特征里有没有物理"。
→ 报告必须每次提到格 B 都写这一点。

### 4.2 t=600 在两个专家上的语义不同

两个专家共享 flow-matching 加噪形式，所以 σ 的定义相同（σ = t/1000）。
但"t=600 对这个专家困不困难"不同：对低噪声专家这是**它训练区间的起点附近**，
对高噪声专家这是**它从未训练过的区间**。

→ 所以 Q2 的 Δ **混合了"专精"与"泛化"两件事**。这是设计固有的限制，
   不能用本轮数据分开。报告必须写明。

### 4.3 参考层

两个专家都是 40 层 → `L16`（40% 深度）与 `Lrel = round(0.533×40) = 21`（52.5%）。
与 E8 对 40 层模型（Wan2.1-14B）的处理一致，**两层都报**。
