## 1. C2a — 可写的结论（不止一条）

### 1.1 E6 产出

**四篇核心论文没有一篇报告 D1（随机初始化下界）。**
逐篇机械检索 `random(ly) initiali[sz]ed` / `untrained` / `from scratch` / `random weights`，
四篇的 `untrained` 与 `from scratch` 命中数**全为 0**，两处近似物都已辨明不是 D1
（`2603.14294` 的 `Random Sel.` 是随机**分数**、`2606.09646` 的 Random Labels 是 **D4 地板**）。

配套的 D1–D6 × 4 论文核对表已完成，每格带原文依据。

### 1.2 E7 产出

**同一套诊断在两个数据集上给出相反的 D1 判定、相同的 D2 失败。**

| | LikePhys | IntPhys 2 |
|---|---|---|
| D1 训练增量占比 | 28.5% ❌ | **88.5% ✅** |
| D2 外观对照 vs 物理 | 1.0000 vs 0.9686 ❌ | **1.0000 vs 0.6458 ❌** |
| D3 饱和单元 | 5/12 | **0/5** |
| D4 | 通过 | 4/5 通过 |

→ **协议既能区分 benchmark（D1），又能暴露系统性问题（D2）。**
HANDOFF 预设的两个分支**同时发生**，比任一单独分支都更有信息量。

### 1.3 两者交叉印证（本轮最有价值的部分）

E6 读原文发现 LikePhys 的变色是 **"color changes mid-flight"**（含时序突变）且被列为**违反项**
→ 我们此前在 LikePhys 上的 D2 存在时序混淆。
E7 自造的对照是**逐帧同一变换**（V 通道差 0.000000、帧间差分相关 0.9989），
**去掉该混淆后结论不变**（弱档 AUC 0.9980 vs 物理 0.6458）。

**E6 发现了我们自己的一个混淆，E7 恰好排除了它。**

### 1.4 一个悬置矛盾被解决

`PREREG.md` §5 原要求：「我们的 `vae_latent` 0.8200 与 Invisible Hand『信号不在 VAE latent』
冲突，必须报告且说明设定不同，不可直接对比」。

本轮把设定往对方挪一步（IntPhys 2 是他们所用 IntPhys 的后继）：

| 设定 | VAE latent AUC |
|---|---|
| LikePhys | 0.8200 |
| **IntPhys 2** | **0.5358** |

→ 那条不一致是 **LikePhys 特有**，不是普遍性质。**§5 的这条口径可以更新。**
