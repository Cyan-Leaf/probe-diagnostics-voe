# E13 — 非生成式编码器上的 D1/D2（V-JEPA 2）

生成：2026-10-28　·　协议：`PREREG.md` D1/D2 + `results/E13_non_generative/E13_PREREG.md`

本文每个数字都能在同目录的 JSON 里按字段路径查到：`E13_cells.json` 给逐格原始值，`E13_verdict.json` 给判定。

## 1. 结论先行

**E13 问的是：E8 那两条结论是不是"生成式去噪模型"的特性。**

答案分两半，而且**两半方向相反**：

1. **D2 完全重现**：V-JEPA 2 上外观扰动 AUC = **1.0000**，物理违反 AUC = **0.7241**，gap **+0.2759**，判 **fail**。
   → "probe 更擅长读编辑痕迹而不是物理"**不是去噪训练的产物**，在一个非生成式、非重建、无 VAE、无加噪步的编码器上同样成立。这是本次最强的结果。

2. **D1 没有变低，反而更高**：V-JEPA 2 的 **D1 = 92.9%**（clean 输入），而 E8 里 Clean 口径的对照格 CogVideoX-2b t=0 是 **78.4%**。
   两者都远高于 50% 阈值。
   → 在**干净输入**上，"训练贡献大部分可分性"这一点在生成式与非生成式编码器上都成立。
   **E8 §1 那句"训练只贡献少数信号"因此不能写成跨模型的通性**——它依赖读出发生在哪个噪声水平，也依赖哪个数据集。

这两条合起来把 E8 的结论边界钉死了一格：**D2 是稳健的、可以推广到非生成式模型；D1 的数值不可推广，能推广的只有它在 IntPhys 2 上"pass"这个方向。**

## 2. 模型与口径

- **`facebook/vjepa2-vitl-fpc64-256` @ `b3c1679b7c34d3255ef3547f27c7b226aefab26f`**
- ViT-L，0.326B，**24 层**，hidden 1024，patch 16，tubelet 2
- 训练目标：**联合嵌入预测（JEPA）**。不是去噪，不重建像素，**没有 VAE**
- 输入：模型原生的 **64 帧 @ 256×256**（pos embed 写死；改尺寸会静默插值，见 `E13_PREREG.md` §4.1）
- token：`32 × 16 × 16 = 8192`
- 参考格：**L16**（绝对层）+ **L13**（53.3% 相对深度，与 E8/E12 同规则）

### 2.1 三处必须声明的偏离

| 偏离 | 原因 | 后果 |
|---|---|---|
| **没有 t=600** | 模型无加噪步 | D1 在**干净视频**上定义，与 E8 的 noised D1 **不可比数值** |
| **没有 VAE latent 下界** | 模型无 VAE | 四组下界只剩三组，`vae_latent` 记为 `null` 而非找替代 |
| **分辨率 256 而非 512** | pos embed 写死 256 | 物理证据的像素带宽比 E8 小（与 E12 §4.2/§4.3 同类问题） |

### 2.2 地板定义换了，必须说明

E8 用 **seed-spread**（feature seed 0/1/2 的 AUC 标准差）。V-JEPA 2 是确定性前向，**没有 feature seed**，这个地板不存在。

→ 改用 **PREREG.md D4 定义 B（标签置换）**：在场景内打乱标签、重拟合，取 AUC 分布的标准差，20 次置换。D4 原本就是为"能否推广到别的 clip"这个问题预注册的，正是 E13 要问的。
→ 两个定义**不可互换**，所以 E13 的 `floor` 不能与 E8 的 `floor` 并列比较。

## 3. 三组下界（参考格 L16，flat 口径）

| 量 | AUC | 说明 |
|---|---|---|
| raw pixel（32×32 RGB，按 tubelet 分组） | **0.5569** | 与权重无关 |
| random-init ViT | **0.5160** | norm-aware 初始化；between-clip std **4.203**（50 clip，未塌陷；见 §3.1）|
| **trained ViT** | **0.7241** | |
| VAE latent | — | 不存在 |

排序 **trained > raw pixel > random**，与 E8 在 7 个扩散模型上的排序一致。

### 3.1 随机初始化没有塌陷（这条最初报错了，已更正）

E13 报告初稿写的是「between-clip std **0.032**（未塌陷）」。**那是在 n=2 个 clip 上算的**，
样本量远不足以判断塌陷，是一个不该出现的数字。

改用 **50 个 clip**（L16，1024 维、32768 个分量）重算，结果写进 `manifest.json` 的
`random_init_check`：

| 权重 | between-clip std | mean\|x\| |
|---|---|---|---|
| trained | 0.5244 | 1.0928 |
| **random** | **4.2031** | 6.7539 |

结论不变（random 的 std **不为零**，没有复现 CogVideoX 上那个 "std = 0.000000" 的塌陷），
但**量级完全不同**：random 初始化的特征幅度和 clip 间变异都比训练后**更大**，不是更小。
这与它 AUC 只有 0.5160（接近随机）并列时是有信息量的：**变异大 ≠ 可分**，
random 网络输出的是大幅度的、与物理标签无关的随机方向。

→ 更正理由写在这里而不是静默改数：`E8_REPORT.md` §12 与 `START_HERE.md` 硬规则⑤都要求
自曝错误优先于产出好看。一个 n=2 的统计量被当作"未塌陷"的证据，是同一类问题的轻量版。

注意 **trained 的 0.7241 高于 E8 所有扩散 backbone 的 t=600 值（0.55–0.67）**。这不是"V-JEPA 更懂物理"的证据：几何不同（256 vs 512、64 帧 vs 49 帧），且输入是干净视频而非 t=600 的强噪声 latent。该数字只能在本表内部读。

## 4. D1：训练贡献占比

`D1 = (AUC_trained − AUC_random) / (AUC_trained − 0.5)`

| 单元 | 层 / 口径 | AUC_trained | AUC_random | 地板 | **D1** | T10 |
|---|---|---|---|---|---|---|
| **V-JEPA 2** | L16 / flat | 0.7241 | 0.5160 | 0.0181 | **92.9%** | 可解读 |
| V-JEPA 2 | L13 / flat | 0.7023 | 0.5237 | 0.0190 | 88.3% | 可解读 |
| V-JEPA 2 | L16 / timeavg | 0.6624 | 0.5087 | 0.0124 | 94.6% | 可解读 |
| V-JEPA 2 | L13 / timeavg | 0.6584 | 0.5182 | 0.0103 | 88.5% | 可解读 |
| **CogVideoX-2b** | L16 / **t=0（干净）** | 0.6099 | 0.5237 | 0.0127 | **78.4%** | 可解读 |

### 4.1 与 E8 的关系（这是本文最容易被误读的地方）

| 口径 | 输入 | CogVideoX-2b 的 D1 |
|---|---|---|
| E8 主格 t=600 | 97.7% 噪声 | 85.3% |
| E8 辅格 t=298 | SNR 匹配 Wan | 92.5% |
| **E13 新增 t=0** | **干净 latent** | **78.4%** |
| **E13 V-JEPA 2** | **干净视频** | **92.9%** |

三点：

1. **把噪声降到 0，D1 没有降到 50% 以下**（78.4%）。所以"训练只贡献少数信号"这个说法在 CogVideoX 上**不是噪声造成的**。
2. **换到非生成式编码器，D1 依然高**（92.9%）。
3. 所以 E8 §1 的原始措辞需要改：**"训练只贡献少数信号"只在 LikePhys 上成立**（E8：7/7 fail，28.5–43.5%），在 IntPhys 2 上从来就不成立（6/7 pass，79.4–99.1）。E8 §14.5 已经把它改成"这些 benchmark + 线性读出的特性"，E13 把这个改法**验证了**：不是 backbone 的特性，也不是训练目标的特性，**是数据集的特性**。

### 4.2 D1 高≠有物理理解

`raw_pixel` 是 0.5569、`random` 是 0.5160、`trained` 是 0.7241。训练确实让特征比随机初始化好读得多 —— 但同一个特征的**外观版本能读到 1.0000**（§5）。所以 D1 高只能说明"训练让这个方向变得线性可分"，**不能说明可分的是物理**。这正是 D2 存在的理由。

## 5. D2：属性无关扰动对照（**E13 的主要结果**）

| 层 / 口径 | 物理 AUC | 外观 AUC | gap | 判定 |
|---|---|---|---|---|
| L16 / flat | 0.7241 | **1.0000** | +0.2759 | **fail** |
| L13 / flat | 0.7023 | **1.0000** | +0.2977 | **fail** |
| L16 / timeavg | 0.6624 | 0.9999 | +0.3375 | **fail** |
| L13 / timeavg | 0.6584 | 0.9999 | +0.3415 | **fail** |

外观对照沿用 E8 的 `cj` 变体（逐帧恒定 HSV 扰动，hue 0.35 / sat 1.4），是**同一个扰动**，不是相似但新的扰动。

### 5.1 这条为什么重要

E8 §14.2 的 12/12 全部 fail 覆盖了四个家族、两种加噪、1.3B–14B —— 但**全是生成式扩散模型**。一个自然的反驳是："这是去噪目标的产物，模型被训练来读'这个东西是不是被加过扰动'。"

E13 直接否掉这个反驳：V-JEPA 2 **不做去噪、不重建像素、没有 VAE**，它对"逐帧恒定的色相偏移"的可分性仍然是 **1.0000**，而同一批特征对物理违反只有 0.7241。

→ **D2 不是扩散模型的特性。** 目前跨 6 个模型族（Wan / CogVideoX / LTX / Mochi / HunyuanVideo / V-JEPA 2）、
**28 个 D2 格全部 fail**，无例外（按独立提取计是 17 个单元：
同一层内 flat / timeavg 只是同一次提取的两种读出，不算两次复现）。
格数由 `scripts/audit_d2_count.py` 从各交付 JSON 数出，见 `results/D2_TALLY.json`——
这个数手工数错过三次（13 → 20 → 28），现在只引用脚本。

### 5.2 天花板问题照旧声明

外观 AUC 在 IntPhys 2 上已经顶到 1.0000，与 E8 一样是**天花板**。所以 gap 的**大小**不可解释；可解释的是**方向**，而方向在物理 AUC 从 0.55 到 0.72 的范围内都成立。

## 6. 判定（`E13_verdict.json`）

```json
{
  "q1": {"d1_pct_vjepa": 92.9, "d1_pct_cogvideox_t0": 78.4, "verdict": "both_above_threshold"},
  "q2": {"auc_physics": 0.7241, "auc_appearance": 1.0000, "verdict": "fail"}
}
```

**没有用 "consistent/inconsistent" 作标签**：这两个词会产生歧义 —— 既可读作"与 E8 一致"，也可读作"两个格彼此一致"。标签改为直接命名观测到的状态（`both_above_threshold` / `both_below_threshold` / `mixed`）。

### 6.1 规模轴：ViT-H 比 ViT-L 更弱

`E13_PREREG.md` §2 原本把 ViT-H 排在主结果之后；主结果出来后才跑，现补上：

| 模型 | 参数量 | 层 | 参考层 | real AUC | random | 外观 | **D1** | 判定 |
|---|---|---|---|---|---|---|---|---|
| V-JEPA 2 **ViT-L** | 0.326B | 24 | L16 | **0.7241** | 0.5160 | 1.0000 | **92.9%** | pass |
| V-JEPA 2 **ViT-H** | 0.6B | 32 | L16 | **0.6584** | 0.5265 | 1.0000 | **83.2%** | pass |
| ViT-H | | 32 | L17（53.3%）| 0.6818 | 0.5265 | 1.0000 | 85.4% | pass |

**更大的模型 real AUC 更低**（0.6584 < 0.7241，差 **−0.0658**），
且两层都低于 ViT-L 的对应层。这不是噪声：ViT-H 的 perm floor 是 0.0167，
比 ViT-L 的 0.0181 还小。

三件事：

1. **判定方向不变**：两个规模都 pass、都 D2 fail。所以 §1 的两条结论不依赖规模。
2. **D1 数值随规模下降**，方向与 E8 §14.4 的"非单调"一致 —— E8 里 10B 的 Mochi（79.4%）
   也低于 1.3B 的 Wan（91.2%）。两处独立观察同向。
3. **不能读作"ViT-H 不懂物理"**：几何、预处理、probe 全同，只换宽度和深度；
   real AUC 降 0.0658 的原因本轮**无法确定**（可能是更深层的特征更抽象、也可能只是
   训练超参不同）。报告只陈述观测。

数据：`E13_cells_vith.json`；两个层的 perm floor 用 5 次置换（不是 20），
因为这是规模轴的辅助格，不是主判定。

### 6.1.1 LikePhys 侧：规模效应**方向相反**（这是必须写的反例）

E15 原报告写着「ViT-H 的 LikePhys 未做」，现已补上（`E13_cells_vith_likephys.json`，
6 个 probe 划分）。结果与 IntPhys 2 **方向相反**：

| 模型 | IntPhys 2 D1 | LikePhys D1 |
|---|---|---|
| ViT-L（0.326B，24 层）| **0.7241** AUC / 92.9% | **49.4% ± 2.29**（5/6 低于 50%）|
| ViT-H（0.6B，32 层）| **0.6584** AUC / 83.2% | **54.1% ± 3.40**（1/6 低于 50%）|

- **IntPhys 2**：更大的模型 real AUC 更低（−0.0658）
- **LikePhys**：更大的模型 D1 **更高**（+4.68 个百分点 = 1.64 个合并 sd）

→ **§6.1 第 3 条那个"规模影响"的说法必须收窄**：它只在 IntPhys 2 的 real AUC 上成立，
   **在 LikePhys 的 D1 上是反的**。两处都各自只有一个规模对，**都不足以支撑任何
   "规模↑ → 表现↑/↓" 的方向性主张**。

→ 这正好与 E16 的发现合上：E16 实测 probe 划分的 sd 是 **1.12–3.41**（中位 1.72 on LikePhys），
   而这里 ViT-L 与 ViT-H 的差是 **+4.68 个百分点**、sd 分别是 2.29 / 3.40 —— **差距 1.64 个合并 sd**，
   处于"可能真实、也可能不是"的地带。
   **所以诚实的写法是：两个规模在 LikePhys 上的 D1 都压在 50% 阈值附近
   （49.4% 与 54.1%），无法判定谁更接近阈值。**

注意 ViT-H 的 54.1% 是 **1/6 划分低于 50%**，即它主要落在阈值**之上**；
ViT-L 是 **5/6 低于**。这个分布上的分离比均值差更值得记，但同样不足以支持方向性结论，
因为两者的 ±1sd 带（ViT-L 47.1–51.7；ViT-H 50.7–57.5）只是**刚好**分开。

### 6.2 敏感性

两个备选格与参考格**判定方向相同**（都是 ≥50%）：L13 flat 88.3%，L16 timeavg 94.6%。维度受控的 timeavg 口径没有把 D1 拉下来，说明 D1 高不是"输入维度大"造成的。

## 7. 对论文写作的直接后果

1. **D2 可以写成跨范式结论**：6 个模型族、28/28 格（19 个独立单元）、含一个非生成式编码器、零例外。这是全文最稳的一条。
2. **D1 必须写成数据集依赖**，不能写成"训练贡献少数信号"的普适结论。IntPhys 2 上 D1 高（含非生成式），LikePhys 上 D1 低。
3. **"generative vs non-generative" 这条边界可以写**，且是有实验支撑的：**D2 跨过这条边界**（§5），
   而 **D1 的数值没有跨过**：IntPhys 2 上两者都 ≥75%，但 LikePhys 上生成式 8/8 落在 27.0–43.5%，
   非生成式是 **49.4% ± 2.3**（E15）。差距 5.9 个百分点，方向一致但**不足以判为同一侧**。
4. **~~Limitations 增一条~~：已由 E15 补测。** 原限制写的"非生成式编码器上 D1 也低**尚未检验**"
   现已检验，结果是 `at_threshold`（六个 probe seed 里 5 个低于 50%，均值 49.41%，sd 2.29%）。
   → 现在的限制陈述应改为：**"非生成式编码器的 D1 落在判定阈值上，与生成式模型的 27–44%
   有明显但不超过噪声带的差距，因此不足以支持也不足以否定『训练目标不影响 D1』。"**
   详见 `results/E15_likephys/E15_REPORT.md`。

## 8. 复现

```bash
export HF_HOME=$HF_HOME

# 特征（每卡一个条件，四条件四卡；同一条件不能分到两张卡）
CUDA_VISIBLE_DEVICES=i python scripts/e13_extract.py --dataset intphys2 \
    --weights {real,random} --variant {plain,cj}

# CogVideoX-2b 干净对照（E13_PREREG.md §3.1 必需）
CUDA_VISIBLE_DEVICES=i python scripts/e12_extract.py --model cogvideox2b \
    --size 512 --frames 49 --dataset intphys2 --weights {real,random} \
    --variant {plain,cj} --t-grid 0 --tag T0

# 分析 + 判定
python scripts/e13_analyse.py --perm-draws 20 --threads 2 --workers 16
python scripts/e13_verdict.py
```

`e13_analyse.py` 必须并行跑：单个 probe 在 n=1012、32768 维下是 32 秒，串行 15 个任务 × 21 次拟合约 3 小时。首次串行运行时忘了 `threadpool_limits`，224 线程把 300×300 的 Gram 矩阵拖慢了 **12 倍**（118s → 9.6s），这一条已写进脚本注释。

**确定性**：V-JEPA 2 前向无随机性，5/5 clip 重跑逐位相同（已验证）。因此 `feature_seeds` 记为 `[0]`，与扩散 backbone 的 `[0,1,2]` 不同 —— 这是模型性质，不是省事。
