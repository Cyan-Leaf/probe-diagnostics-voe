## 0. 判定

**E0 通过（t ≤ 600），在 t ≥ 800 不通过。**

| | t=200 | t=400 | **t=600** | t=800 | t=950 |
|---|---|---|---|---|---|
| 配对效应（violation − valid） | −0.01859 | −0.01331 | **−0.00966** | −0.00583 | −0.00235 |
| 相对效应 | −9.58% | −11.49% | **−10.88%** | −6.61% | −1.27% |
| **仅换种子引起的效应波动（噪声地板）** | 2.15e−4 | 1.14e−4 | **2.08e−4** | 6.20e−4 | 4.64e−3 |
| **效应 / 地板** | **86.6×** | **116.4×** | **46.4×** | 9.4× | **0.51×** |
| Wilcoxon p（n=120 配对） | 2.0e−7 | 3.0e−6 | **1.7e−4** | 0.127 | 0.883 |
| 种子噪声占总方差 | 0.004% | 0.015% | 0.065% | 0.386% | 4.32% |

- **t ≤ 600：效应是种子地板的 46–116 倍，可以报 delta。**
- **t = 800/950：效应落进噪声里（p = 0.13 / 0.88），该区间的 delta 不可报。**
  这一点无人报告过——`2603.14294` 的 timestep 网格只到 600，没测过高噪声区。

规模：920 clips × 5 timesteps × 5 seeds = **23,000 次单次 forward**（含特征捕获共 ~2.8 GPU·小时，3 卡并行 ~55 分钟）。

## 1. 三层噪声地板（这是新方案里误差棒的来源）

### 1.1 clip 级：同一 clip、同一 t，只换噪声 seed

| t | 中位 CV | 中位极差/均值 | p90 极差/均值 | 中位 seed std |
|---|---|---|---|---|
| 200 | **0.44%** | 1.05% | 2.22% | 6.7e−4 |
| 400 | 0.86% | 2.13% | 5.53% | 7.8e−4 |
| **600** | **1.49%** | 3.61% | 8.17% | 1.11e−3 |
| 800 | 2.73% | 6.76% | 12.78% | 2.23e−3 |
| 950 | **7.39%** | 17.97% | 30.57% | 1.32e−2 |

→ **噪声随 t 单调上升，t=950 时单 clip 的测量已不可用（中位极差 18%，p90 达 31%）。**
→ T2 在单个 clip 上看到的 5.9% 极差（t=600, 3 seeds）与这里的分布一致（p90 = 8.2%）。

### 1.2 效应级：同一效应估计，只换 seed 重算

见 §0 表第 3 行。5 个 seed 各自得到的平均效应在 t=600 时为
−0.00972 / −0.00952 / −0.00971 / −0.00963 / −0.00973，极差 2.08e−4
—— 即**效应本身的估计非常稳**，不稳的是单 clip 的测量。
这正是「多 seed 平均」与「固定 seed」都要做的理由（SPEC §6.1）。

### 1.3 probe 级

见 T4 报告：同配置换噪声 seed 重训线性 probe，AUC 中位波动 **0.0104**（p90 0.0253）。
这是 E1 判据里 2× 阈值的来源。

## 2. 主效应的方向与分布（必须看清，否则会讲错故事）

**总体方向为负：违反物理的 clip 的 denoising error 比合法 clip 更 *低*（t=600：0.0801 vs 0.0888）。**
这与「模型对不合理视频更意外」的朴素预期**相反**。

t=600 细节：

| 量 | 值 |
|---|---|
| 均值配对差 | −0.00966 |
| **中位配对差** | **−0.00091** |
| bootstrap 95% CI | [−0.01386, −0.00585] |
| 配对 Cohen's d | −0.432 |
| Cliff's delta（非配对） | −0.109（小） |
| 配对中为正的比例 | **39.2%** |

**均值被重尾拖走**：中位数只有均值的 1/10，仅 39% 的配对为正。
per-scenario（t=600）看得很清楚：

| 场景 | 配对差 | 正向比例 | | 场景 | 配对差 | 正向比例 |
|---|---|---|---|---|---|---|
| fluid | **−0.0709** | 0.00 | | block_slide | −0.0002 | 0.40 |
| faucet | **−0.0335** | 0.00 | | ball_collision | +0.0008 | 0.90 |
| cloth_drape | −0.0143 | 0.00 | | ball_drop | +0.0039 | 1.00 |
| river | −0.0081 | 0.00 | | shadow_camera | +0.0039 | 0.70 |
| pyramid | −0.0025 | 0.40 | | flag | **+0.0067** | 0.80 |
| pendulum | −0.0013 | 0.30 | | shadow | −0.0006 | 0.20 |

→ **四个流体/柔体场景（fluid / faucet / cloth_drape / river）全部 0.00 正向比例、量级最大**，
把全局均值拉成负的；刚体与阴影类场景则多为正。
**全局均值在这个数据集上是误导性的**（SPEC §6.3 要求 per-scenario 优先，这里是具体例证）。

一个与之一致的机械解释（**属于假设，未验证**）：流体/柔体的违反编辑（`sudden_freeze`、
`phase_transition`、`teleporting_fluid`、`rubber_cloth` 等）往往**降低**画面的运动/纹理复杂度，
而 denoising error 对复杂度高度敏感。要排除它需要做「复杂度匹配」的对照，本轮未做。

## 3. 两个对照组（同一配对检验，同一地板）

| 对照 | t=200 | t=600 | 判定 |
|---|---|---|---|
| **`temporal_disorder`（帧序打乱，外观不变）** | +0.0640（+33.0%），p=2e−21 | **+0.0358（+40.4%）**，CI [0.0316, 0.0401] | **强正、极显著**，是物理效应量级的 3.7 倍 |
| **`color_change`（纯外观改变，物理合法）** | −0.0008（−0.42%），p=0.095 | **−0.0015（−1.7%）**，CI [−0.0076, +0.0040] | **零效应**，CI 跨 0 |

这两条对 denoising-error 指标是**好消息**：
它对**时序破坏极敏感**、对**纯外观改变不敏感**。
（注意：T4 显示**线性 probe 的行为与此相反** —— 见 T4 报告 §3，这是本轮最重要的发现。）

## 4. 方法学备注

- 配对单位 = `(scenario, subgroup)`，n = 120；每个 subgroup 内 1 个 valid vs 其全部 violation clips 的均值。
- 统计：Wilcoxon 符号秩（双侧）+ 配对差 bootstrap 95% CI（10,000 次，seed 12345）+ Cohen's d + Cliff's delta。
- 所有结果文件带 `env`（torch/diffusers/GPU 物理设备/模型 revision）与 `preflight`（GPU 自检）。
- **物理 GPU 0 因缺陷 SM 被排除**，见 `results/T2_env/T2_REPORT.md` §0。

## 5. 给负责人的三点

1. **E0 可以交**：噪声地板已量化到三个层级，t ≤ 600 区间的 delta 可报，t ≥ 800 不可报。
   这比 `2603.14294`（全文 0 处方差/CI/p 值）严格，且直接补上了它的最大缺口。
2. **效应方向为负、且由 4 个流体/柔体场景主导** —— 这会影响 ShowGap_rep 的符号约定与叙事口径，
   属方案层面，本 agent 未做任何重新定义。
3. **denoising-error 指标与线性 probe 在对照组上的表现不一致**（前者对 color_change 免疫、
   后者完全不免疫，见 T4 §3）。两者不能混着讲。
