# E16 — E8 的 D1 对 probe 划分的敏感性

生成：2026-10-29　·　协议：`results/E16_probe_seed/E16_PREREG.md`

数据：`E16_cells.json`（144 个格 × 每个 6 个 probe 划分偏移）。
3 线程版本保留在 `E16_cells.threads3_superseded.json`，理由见 §2.2。

---

## 1. 结论先行

**E8 的判定站得住；但 E8 内部的"谁比谁高"这类排序，有一半是噪声。**

| 结论 | 结果 |
|---|---|
| 12 个格的 pass/fail 判定是否被 probe 划分影响？ | **11/12 稳定**，只有 LTX@IntPhys2 翻转（而它本来就是 NOT interpretable）|
| IntPhys 2 上的 pass 有多少余量？ | 最差 seed 也高出阈值 **+29.4 到 +43.7 个百分点** |
| LikePhys 上的 fail 有多少余量？ | 最差 seed 也低于阈值 **6.5 到 16.6 个百分点** |
| E8 内部排序能不能写？ | **不能**。最典型的一对：LikePhys 上 CogVideoX-2b 41.2% vs 5b 41.0%，**差 +0.2 个百分点，而两者 sd 是 1.84 / 1.96** |

→ **E8 的每一个 pass/fail 判定都不依赖运气；但"5b 比 2b 更接近阈值"这种话不能写。**

余量按**最差的那个划分**算（不是均值），逐个格：

| IntPhys 2（应 > 50%）| 最差 seed 的余量 |
|---|---|
| Mochi-1 | +29.4 pp |
| CogVideoX-2b | +30.7 pp |
| CogVideoX-5b | +36.2 pp |
| Wan2.1-1.3B | +41.2 pp |
| Wan2.1-14B | +43.7 pp |

| LikePhys（应 < 50%）| 最差 seed 距阈值 |
|---|---|
| CogVideoX-5b | 6.5 pp |
| CogVideoX-2b | 6.8 pp |
| Mochi-1 | 14.3 pp |
| LTX | 14.8 pp |
| Wan2.1-14B | 15.3 pp |
| Wan2.1-1.3B | 16.6 pp |

**最小的余量是 LikePhys 上 CogVideoX 的 6.5 pp**，仍大于它自己的 sd（1.84–1.96）的 3 倍。

## 2. 设计

### 2.1 轴：probe 的 CV 划分偏移，不是特征

E8 的每个格是 `probe(..., seed = 1000 + feature_seed)` —— **probe 的 CV 划分与 feature seed 耦合**。
E16 把这个偏移从 1000 扩到 6 个值：`{1000, 2000, 3000, 4242, 5000, 6000}`，feature seed 仍是 0/1/2。

**offset = 1000 那一列必须逐位复现 E8**，这是本分析的自检。实测：

```
12 个格，diff 全部 0.0000（12/12 OK）
```

### 2.2 一个必须记录的踩坑：thread 数会改变数值

第一次跑用 3 个 BLAS 线程，自检差了 0.6–6.2 个百分点。实测原因是**数值**而非算法：

| threads | cogvideox2b@intphys2 random (offset 1000) |
|---|---|
| **4** | **0.5212671690375497** ← 与 E8 逐位相同 |
| 1 | 0.5213261335383826 |
| 3 | 0.520435 |

LBFGS 在这个病态问题上（300×300 Gram、p≫n）不收敛到唯一点，线程数会改变最后一次迭代的路径。
→ **结论：这个 probe 只在固定线程数下可复现**，E8 用的是 4（`--threads` 默认 4）。
→ E16 已用 4 线程重跑，3 线程版本保留为 `*.threads3_superseded.json` **不删除**，
   因为它正是这个坑的证据。

⚠️ **这条对 E8 本身也是一个新发现的漏洞**：E8 的 `e8_analyse.py` 把 threads 做成参数
（默认 4），而 `E8_cells_*.json` 没有记录当时用的是几线程。**如果当时不是 4，E8 的数字会不可复现。**
E16 的 12/12 逐位复现说明**当时确实是 4**，但这是**事后推断**，不是记录在案的。

### 3.1 LTX@IntPhys2 的翻转说明什么

E8 对它的判定是 **NOT interpretable**（T10 门槛：效应 ≤ 2×地板），**不是 pass 也不是 fail**。
E16 证实这个判定是对的、而且是**必须的**：它的 D1 在 6 个划分里从 38.2% 摆到 52.9%，
**跨过了 50%**。若 E8 当初直接报 48.5% 为"接近阈值但不通过"，会掩盖这个量级的不确定性。

→ 换句话说：**LTX@IntPhys2 是唯一一个"判定不稳"的格，而 E8 已经用 T10 把它排除在判定之外了。**
这条不是 E8 的缺陷，是它的成功。

### 3.2 排序问题：这是 E16 最有用的产出

| 一对 | 差距 | 各自 sd | 能否支持"谁更高" |
|---|---|---|---|
| CogVideoX-2b vs 5b @ LikePhys | **+0.2 pp** | 1.84 / 1.96 | **不能** |
| CogVideoX-2b vs 5b @ IntPhys 2 | +5.2 pp | 3.24 / 3.41 | **不能**（差 < sd）|
| CogVideoX-2b vs Mochi @ IntPhys 2 | +2.4 pp | 3.24 / 2.51 | **不能** |
| Wan-14B vs Wan-1.3B @ IntPhys 2 | +4.0 pp | 2.07 / 1.98 | **不能** |

**E8 §14.4 写过"规模效应非单调"（Mochi 10B 低于 Wan 1.3B），这张表说明：**
**所有相邻模型之间的 D1 差距（2–5 个百分点）都在 probe 划分噪声的量级内。**
E8 §14.4 的措辞是"**不足以支持任何『越大越好/越差』的主张**"——E16 **证实了这句话，
而且理由比 E8 写的更强**：不是"关系不单调"，而是"**差距本身测不出来**"。

## 5. 已知限制

1. **只测了 L16 / t=600**。E8 的 `Lrel` 格没有测（预算翻倍），若需要可再跑一遍。
2. **6 个划分不等于分布**。sd 是 6 个点的离散度，不是对"所有可能划分"的推断；
   真实不确定性可能更大（6 个点的 sd 本身有约 30% 的抽样误差）。
3. **只覆盖 E8 的 12 个格**，E13/E14/E15 的格未测（它们的 sd 未知）。
   E15 已用另一种方式（6 个固定 probe seed）给出 V-JEPA 的 sd = 2.29。
4. **线程数的发现是 fortuitous**，不是设计时想到的；它意味着**任何用这个 probe 的历史结果
   都需要记录线程数才能复现**。E8 当时恰好是 4，但那是推断。
