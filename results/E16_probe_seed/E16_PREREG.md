# E16：E8 的 D1 对 probe 划分的敏感性

**写于任何 E16 计算之前：2026-10-29**

本文件补 `E13_PREREG.md` 与 `E15_PREREG.md` 都没覆盖的一层：**probe 自身的 CV 划分 seed**。

---

## 1. 为什么必须做

E15 在 V-JEPA 2 上发现：**同一批特征、同一个 probe，只换 CV 划分 seed，LikePhys 的 D1 就从
43.8% 变到 54.0%**（6 个 seed，均值 49.41% ± 2.29%）。这个摆动**跨过了 50% 判定阈值**。

而 E8 的 24 个格**从来没有变过这个 seed**：它固定用 `1000 + feature_seed`，
三个 feature seed 给出的 spread 只反映**噪声抽样**，不反映 **CV 划分**。

→ 所以有一个直接的问题：**E8 那些 D1 数字里，有多少是 probe 划分噪声？**

## 2. 设计（零 GPU，只读现有 E8 缓存）

- 对 E8 的 **6 个 backbone × 2 个数据集**，在 **L16 / t=600** 上重算 D1
- **probe seed ∈ {1000, 2000, 3000, 4242, 5000, 6000}**（与 E15 同一组，便于横向比）
- feature seed 仍取 0/1/2（与 E8 一致，每个点是三个 feature seed 的均值）
- 其余全部不变：同一 probe 代码路径、同一分组键、同一地板定义

**自检（必须通过）**：`probe_seed = 1000` 那一列必须逐位复现 `E8_cells_*.json` 的 AUC。
不复现说明分析路径有问题，此时**停止**，不继续解读。

## 3. 判据（写死）

对每个格算 D1 在 6 个 probe seed 上的：
- `d1_mean_pct` / `d1_sd_pct` / `d1_min_pct` / `d1_max_pct`
- `verdict_stable`：6 个 seed **全部**在阈值同侧 → 判定稳定
- `verdict_flips`：跨过阈值 → 判定不稳

**这次不设"通过/不通过"**，因为它是**对已有结论的精度刻画**，不是新假设检验。
输出的是"E8 的每个 pass/fail 有多少把握"，而不是"E16 本身过不过"。

### 3.1 会因此改写的三处

1. **E8 §14 的排序**：若两个模型 D1 差距 < 2×sd，则"谁更接近阈值"这类排序不可写。
   已知最危险的一对：LikePhys 上 CogVideoX-2b **42.6%** vs CogVideoX-5b **43.5%**（差 0.9 个百分点）。
2. **E8 §15 的 LTX 层翻转**：L16 48.5% vs L15 60.7%（差 12.2）。若 sd 是 2–3 个百分点，
   这个翻转**仍然成立**，但报告要说明差距里有多少是噪声。
3. **E8 §14.1 的"训练贡献多数信号"**：IntPhys 2 上 77–99%，离阈值远，**预计不受影响**——
   这正是这个分析的价值：它能区分"结论稳"与"结论靠运气"。

## 4. 不做的事

- 不改任何 E8 数字（红线：不手改已交付）。E16 输出独立文件，E8 通过追加 §17 引用它。
- 不重跑特征提取（全零 GPU）。
- 不把 E16 的 sd 当作"置信区间"——它只是**6 个划分之间的离散度**，不是对总体的推断。
