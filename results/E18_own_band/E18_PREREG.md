# E18 预注册：把每个专家放回它自己的噪声区间

**写于任何 E18 提取之前：2026-10-29**

本文解 `E17_REPORT.md` §3.3 与 §5 里写明的未解问题：
**E17 的 Q2 混淆了"噪声区间专精"与"对未训练区间的泛化"**，本轮把这二者拆开。

---

## 1. 为什么必须现在做

E17 测的是 **两个专家都在 t=600**：

| 专家 | t=600（σ=0.600）对它意味着 |
|---|---|
| 低噪声（`transformer_2`）| **在训练区间内**（σ < 0.875）|
| 高噪声（`transformer`）| **越界**（σ ≥ 0.875 才启用）|

结果是两者 D1 几乎相同（99.1% / 99.1%，差 0.06 pp）。但这个比较**不公平**：
一边在主场、一边在客场。所以它只能说明"两个网络都读得出物理"，
**不能**说明"噪声区间的专精不影响可读性"。

→ 要回答后者，必须让**两个专家各自在主场**被测量。

## 2. 设计：2×2 对角 vs 非对角

`boundary_ratio = 0.875`（`model_index.json`，已在磁盘核实）。取两个 t：

- **t = 900**（σ=0.900 ≥ 0.875）→ **高噪声专家的主场**
- **t = 300**（σ=0.300 < 0.875）→ **低噪声专家的主场**

| | t=300 | t=900 |
|---|---|---|
| **低噪声专家** | **主场** ✔ | 客场 |
| **高噪声专家** | 客场 | **主场** ✔ |

**本轮只做对角两个格**（主场 × 主场），因为那才是 Q2 缺的那一半。
非对角两格 E17 已覆盖一半（都在 t=600），不再补 t=300/900 的客场——
理由：客场格回答的是"泛化"，而泛化需要多个噪声水平才能画曲线，单点没有信息量。

## 3. 要回答的问题（判定写死）

### Q：两个专家**各自在主场**时，D1 是否仍然相近？

- **统计量**：`Δ_own = D1(low @ t=300) − D1(high @ t=900)`
- **阈值**：沿用 E16 实测的 probe 划分 sd。**IntPhys 2 的中位 sd = 2.51 pp**
  （`results/E16_probe_seed/E16_cells.json`）。不能用更小的数，否则把噪声当信号。
- **判据**：
  - `|Δ_own| < 2.51` → **`experts_match_in_own_band`**：噪声区间专精不改变 D1
    → 这**加强** E17 的零结果，Q2 的"混淆"问题被解决
  - `|Δ_own| ≥ 2.51` → **`experts_differ_in_own_band`**：E17 的零结果是**越界使用造成的**，
    E17 §5 关于"专精不影响"的表述必须收回

**必须同时报**：`Δ_cross` = E17 已有的 t=600 之差（+0.06 pp），与本轮的 `Δ_own` 并列。
若 `|Δ_own| > |Δ_cross|`，说明**主场比较反而更敏感**，这本身是个结论。

### 附带问题：D1 的绝对水平随 t 怎么变

`t=900` 与 `t=300` 的 σ 相差 3 倍，而 E8 §16.2 已声明弱信号区（real AUC < 0.6）的 D1 不可靠。

- **先决条件**：两格都必须先过 T10 门槛（`效应 > 2×地板` 且 `AUC−0.5 > 2×地板`）
- 不过门槛的格**不报 D1**，只报 `NOT interpretable` + 原始 AUC
- **不做**："t 越大 D1 越高"这类趋势主张——只有两个点，画不出趋势
